# UntilFire brand kit

Approved Next Horizon artwork, 29 October 2026.

- `logo-horizontal.svg`: outlined Inter wordmark and black mark. No font installation needed to display.
- `logo-horizontal-white.svg`: inverse lockup.
- `mark-black.svg`, `mark-white.svg`: transparent stand-alone marks.
- PNG equivalents and icon sizes 16–1024px.
- `app-icon.svg`: yellow square source; allow platform icon masks to apply.
- `brand-tokens.json`, `brand-tokens.css`: palette.
- `fonts/`: Inter static faces 400–800 and SIL Open Font License.

Use black artwork on white or yellow, white on charcoal. Preserve aspect ratio and one mark-height of clear space. No gradients, outlines, glows or shape changes. Main yellow #FFE58A; ink #151719. Refer to `docs/design/design-system.md` in the repository for the full contract.

The mark geometry follows the approved generated final logo, converted to vector; the wordmark uses real Inter outlines rather than generated lettering. This kit is the approved direction, not confirmation of a store/production release.
